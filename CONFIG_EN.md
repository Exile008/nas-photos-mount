# NAS Photos Mount v3 Configuration

[简体中文](CONFIG.md) | [English](CONFIG_EN.md)

## Open the Management Panel

Tap the action button for `NAS Photos Mount` in the Magisk module list. The panel listens only on the phone's `127.0.0.1:8686`, and every API request requires the random token generated by the module.

Use the language control in the top-right corner to switch between Chinese and English. The selected language is stored in the panel's local browser storage.

## SMB Sign-In

In SMB connection, enter the NAS address, port, username, password, and optional domain, then tap Test and save. The module saves a new configuration only after it can list the SMB root.

- Enter a hostname or IP address such as `192.168.1.10`; do not include `smb://`.
- The default SMB port is `445`.
- When a password is already saved, leave the password field empty to keep it.
- The password is obfuscated with `rclone obscure` and stored in `/data/adb/nas_photos_mount/rclone.conf` with file mode `0600`. The management API never returns the password or its obfuscated value.
- Changing the connection automatically remounts all enabled sources.

## Add Multiple Scan Folders

Tap Add folder to create a source, then use Browse to choose a remote SMB folder. Each source stores these settings independently:

- `NAS folder`: use `share/subfolder`, for example `photo/example`.
- `Local album folder`: maps to `/storage/emulated/0/DCIM/<name>`. Two sources cannot use the same name.
- `Enable source`: disabling a source preserves its configuration and dedupe history but unmounts it.
- `Automatic scan`: searches for new or changed files on that source's own schedule.
- `Scan interval`: 15 to 10080 minutes.
- `Registration batch size`: 1 to 5000. Start between 100 and 500 for a large library, observe Google Photos, and increase it gradually.
- `Ignore rules`: apply only to the current source.

Up to 32 sources can be saved. Each source is mounted at `/mnt/nas-photos/<source-id>` and then bind-mounted read-only into its assigned `DCIM` album folder. Removing a source unmounts it first, then archives its configuration and dedupe state in `/data/adb/nas_photos_mount/deleted-sources/`.

## Large Folders and 2 TB Libraries

Mounting does not download the complete NAS folder to the phone. File content travels over SMB only when Google Photos or another media service reads it. The initial scan still traverses directory metadata and may take a long time when a source contains many files.

Start with ignore rules that limit the scan to a small range, then expand it gradually. The status panel shows file count, indexed size, pending registrations, scan status, and last scan time for each source, as well as NAS capacity and mount process health.

## Ignore Rules

Rules support the Syncthing `.stignore` subset implemented by this module:

- Put one pattern on each line.
- Lines beginning with `#` are comments. To match a directory whose name begins with `#`, use `(?d)#folder-name`.
- `*`, `?`, and character ranges such as `[0-9]` are supported.
- `(?d)` is accepted. Because the mount is read-only and does not propagate deletion, it means to ignore the matching directory or file in this module.
- `(?i)` makes all ignore matching for that source case-insensitive.

Ignored content is not shown in the phone's mounted view and is not submitted to Android MediaStore. The default rules are:

```text
2022*
2023*
2024*
2025*
2026-0[1-2]*
#2025-0[1-9]*
#2025-10-0[1-5]*
#2024-05-0[1-9]*
#2024-05-1[1-9]*
# OS generated files #
(?d)$RECYCLE.BIN
(?d)$Recycle.Bin
(?d)#recycle
(?d)System Volume Information
(?d)*Zone.Identifier:$DATA
(?i)(?d)lost+found
```

## Incremental Scans and Duplicate Uploads

Each source keeps a separate record in `/data/adb/nas_photos_mount/sources/<source-id>/state/seen.tsv`. It records the remote folder, local album name, relative path, size, and modification time for media already submitted to Android MediaStore.

- Restarting the program, module, or phone does not resubmit a file whose record is unchanged.
- A file with the same path but a different size or modification time is registered again as changed media.
- During an upgrade from v2, the old configuration is migrated to `source-1` together with the old `seen.tsv`, so existing photos are not resubmitted as a complete batch.
- Registered means Android MediaStore received a scan request. It does not mean that Google Photos completed a cloud upload. Google Photos remains responsible for cloud status and server-side deduplication.

## Data Locations

- SMB configuration: `/data/adb/nas_photos_mount/rclone.conf`
- Multi-source configuration: `/data/adb/nas_photos_mount/sources/`
- Removed source archive: `/data/adb/nas_photos_mount/deleted-sources/`
- Runtime log: `/data/adb/nas_photos_mount/nas-photos.log`
- Management panel token: `/data/adb/nas_photos_mount/web.token`
